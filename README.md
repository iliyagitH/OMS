## Как запустить код
1. Склонируйте репозиторий на локальную машину.
2. Для MATLAB-скриптов откройте MATLAB, сделайте папку нужной лабораторной (`lab1`, `lab2` или `lab4`) рабочей директорией и запустите соответствующий скрипт: `lab1.m`, `lab2.m` или `lab4.m`.
3. Для C++ в `lab4` скомпилируйте и запустите `lab4.cpp` (`g++ lab4.cpp -o lab4`).
