# Лабораторная работа 1: Временная и частотная формы сигналов. Дискретизация

## Описание
В данной лабораторной работе исследуются базовые принципы аналого-цифрового преобразования (АЦП), проверяется теорема Котельникова-Найквиста и проводится анализ спектров. 
Работа выполнена для сигнала по **варианту 13**: 
$y(t) = 6\sin(2\pi \cdot 9t + \pi/5)$.

Расчет спектров реализован **алгоритмически «с нуля»** на основе математической формулы Дискретного преобразования Фурье (ДПФ) через вложенные циклы `for`. 
Встроенная функция быстрого преобразования `fft()` в основном коде намеренно **не используется**.

Из-за высокой вычислительной сложности алгоритма ($O(N^2)$), при спектральном анализе аудиофайла применяется защитное оконное ограничение в 4000 отсчетов, чтобы избежать длительного зависания среды MATLAB.

## 📂 Состав файлов
* `lab1.m` — основной исполняемый скрипт лабораторной работы.
* `dop.m` — скрипт дополнительного задания, реализующий повышение тональности аудиосигнала.
* `voice.wav` — исходный тестовый аудиофайл для анализа и обработки.
* `voice_downsampled.wav` — результат прореживания сигнала (демонстрация алиасинга). Файл генерируется автоматически после запуска lab1.m
* `voice_cartoon.wav` — аудиофайл с обработанным голосом высокой тональности. Файл генерируется автоматически после запуска `dop.m`.

## Основные этапы исследования
1. **Дискретизация:** Расчет минимальной требуемой частоты оцифровки ($f_s > 2f_{max}$) и демонстрация граничных условий Котельникова (потеря сигнала при $f_s = 2f_{max}$).
2. **Спектральный анализ:** Переход из временной области в частотную с помощью программно реализованного ДПФ. Определение ширины спектра.
3. **Алиасинг (Наложение спектров):** Прореживание речевого сигнала в 10 раз (до $4410$ Гц) без предварительной низкочастотной фильтрации. Демонстрация необратимых искажений и переноса высоких частот в низкочастотную область.
4. **Квантование:** Оценка влияния разрядности АЦП (от 3 до 6 бит) на среднюю ошибку и появление паразитных частотных составляющих.

## 🚀 Как запустить
1. Откройте MATLAB.
2. Сделайте текущую папку (где лежит файл `lab1.m`) рабочей директорией.
3. Запустите скрипт `lab1.m`.
