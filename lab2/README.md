# Лабораторная работа 2: Проектирование радиопокрытия мобильных сетей. Модели распространения сигналов. Бюджеты каналов

## Описание
В лабораторной работе рассчитываются энергетические бюджеты восходящего (UL) и нисходящего (DL) каналов мобильной сети и оценивается радиопокрытие с помощью моделей распространения сигнала.

Для расчётов используется частота **1,8 ГГц**. Сначала определяются тепловой шум, чувствительность приёмников и максимально допустимые потери распространения (**MAPL**). Затем строятся зависимости потерь сигнала от расстояния и рассчитывается количество базовых станций для заданных территорий.

При построении моделей приняты дополнительные параметры: высота антенны БС — **30 м**, высота антенны телефона — **2 м**; для модели Walfish–Ikegami — высота зданий **15 м**, ширина улиц **20 м**, расстояние между зданиями **40 м** и угол **45°**.

## 📂 Состав файлов
* `lab2.m` — основной исполняемый скрипт лабораторной работы.

## Основные этапы исследования
1. **Расчёт UL и DL:** определение уровня теплового шума, чувствительности приёмников и MAPL с учётом коэффициентов шума, SINR, усиления антенны и дополнительных потерь.
2. **Модели распространения:** построение графиков потерь по моделям UMiNLOS, COST231 Hata (Urban) и Walfish–Ikegami. На графиках также показаны уровни MAPL для UL и DL.
3. **Радиусы сот:** нахождение расстояний, при которых потери распространения достигают MAPL. Рабочий радиус определяется по более ограничивающему направлению связи.
4. **Расчёт количества БС:** оценка площади покрытия трёхсекторной базовой станции по формуле $S = 1{,}95R^2$ и количества станций для территорий **100 км²** и **4 км²**.

В используемом варианте получены **MAPL UL ≈ 126,7 дБ** и **MAPL DL ≈ 144,1 дБ**. Ограничивающим является восходящий канал. По принятой модели покрытия требуется **129 макро-БС** на 100 км² и **11 микро-БС** на 4 км².

## Как запустить
1. Откройте MATLAB.
2. Сделайте текущую папку (где лежит `lab2.m`) рабочей директорией.
3. Запустите скрипт `lab2.m`.
4. Результаты расчётов появятся в Command Window, а сравнительный график моделей распространения — в отдельном окне.
