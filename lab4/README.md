# Лабораторная работа 4: Изучение корреляционных свойств последовательностей, используемых для синхронизации в сетях мобильной связи

## Описание
В лабораторной работе исследуются псевдошумовые двоичные последовательности (коды Голда), формируемые с помощью двух 5-разрядных линейных регистров сдвига с обратной связью (LFSR), а также их автокорреляционные и взаимокорреляционные свойства.

Работа выполнена для нечётной группы (схема генерации по рис. 4.5: `x1 = x4 ⊕ x5`, `y1 = y2 ⊕ y5`, выход `out = x5 ⊕ y5`) и номера в журнале 12. Длина формируемых последовательностей составляет $N = 2^5 - 1 = 31$ бит:
* для первой последовательности: $x_1 = 12$ (`01100`), $y_1 = x_1 + 7 = 19$ (`10011`);
* для второй последовательности: $x_2 = x_1 + 1 = 13$ (`01101`), $y_2 = y_1 - 5 = 14$ (`01110`).

Реализация выполнена на двух языках (C++ и MATLAB) с последующим сравнением полученных результатов.

## 📂 Состав файлов
* `lab4.cpp` — программа на C++ для генерации последовательностей Голда, расчёта циклической автокорреляции (сдвиги `0..31`) и взаимной корреляции.
* `lab4.m` — скрипт MATLAB, выполняющий генерацию тех же последовательностей, расчёт корреляций встроенными функциями `autocorr()` и `xcorr()` и построение графиков автокорреляции от величины задержки (`lag`).

## Основные этапы исследования
1. Генерация первой последовательности Голда (`seq1`): формирование 31-битной последовательности по схеме рис. 4.5 из начальных состояний `x1 = [0 1 1 0 0]` и `y1 = [1 0 0 1 1]`.
2. Автокорреляционный анализ в C++: выполнение поэлементного циклического сдвига `seq1` вправо для всех задержек `0..31` и вычисление нормированной автокорреляции по формуле $R(\tau) = \frac{\text{совпадения} - \text{несовпадения}}{N}$ с выводом результирующей таблицы.
3. Генерация второй последовательности (`seq2`) и взаимная корреляция: формирование последовательности для `x2 = [0 1 1 0 1]`, `y2 = [0 1 1 1 0]` и расчёт взаимной корреляции с `seq1` при нулевом сдвиге.
4. Реализация и визуализация в MATLAB: повторение расчётов в MATLAB с переводом бит в биполярный вид (`0 → -1`, `1 → +1`), вычисление корреляций через `autocorr()` и `xcorr(..., 'coeff')`, сравнение с C++ и построение графиков `stem` зависимости автокорреляции от задержки `lag`.

В результате получено точное совпадение сгенерированных последовательностей и значения взаимной корреляции при нулевом сдвиге в C++ и MATLAB: $R_{12}(0) = -3/31 \approx -0{,}0968$. При ненулевых сдвигах значения автокорреляции в C++ и MATLAB отличаются, так как в C++ вычисляется циклическая (периодическая) автокорреляция, а `autocorr()` и `xcorr()` в MATLAB рассчитывают нециклическую (линейную) автокорреляцию (причём `autocorr()` дополнительно вычитает среднее значение).

## Как запустить

### C++
1. Скомпилируйте `lab4.cpp`:
   ```bash
   g++ lab4.cpp -o lab4
   ```
2. Запустите полученный исполняемый файл (`./lab4` или `lab4.exe`).
3. В терминале появятся обе последовательности, таблица циклических сдвигов с автокорреляцией и значение взаимной корреляции.

### MATLAB
1. Откройте MATLAB.
2. Сделайте папку `lab4` текущей рабочей директорией.
3. Запустите скрипт `lab4.m`.
4. Последовательности, таблица значений `autocorr()` и взаимная корреляция выведутся в Command Window, а графики автокорреляции (`autocorr` и `xcorr`) — в отдельном окне.
